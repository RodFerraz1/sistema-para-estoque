# 03: UI mínima (fila, chat e onboarding da política)

**Status:** ready-for-agent
**Blocked by:** 02
**Spec:** `.scratch/aprovacao/spec.md` (seção "UI")

## What to build

Três páginas em HTML, CSS e JS puros servidas pelo FastAPI em `/ui`: a fila de aprovação com aprovar, editar e rejeitar; o chat com a resposta, o entendimento e as fontes; e o onboarding que preenche a política de compra com as perguntas do comprador.

## Acceptance criteria

- [ ] `src/ui/` com `index.html` (fila), `chat.html`, `politica.html`, um CSS e um JS por página (ou um comum), montado com `StaticFiles` em `/ui`, e `/` redirecionando para `/ui/`.
- [ ] Fila: gerar, cards na ordem da fila com destaque, aprovar (nome, quantidade editável, justificativa quando a faixa exige), rejeitar (nome, motivo), filtro de aprovadas e rejeitadas, id do pedido depois de aprovar, mensagens de erro da API visíveis.
- [ ] Chat: pergunta, resposta, intenção, confiança, faixa, SKUs, trechos e citações com veredito.
- [ ] Política: perguntas 1 a 9 e os limites das faixas, preenchidas com a política ativa; salvar mostra a versão nova ou o erro; perguntas 10 a 14 só leitura.
- [ ] Testes HTTP das páginas e o teste que confere que os endpoints chamados pelos `.js` existem.
- [ ] Verificação manual: o app sobe (`uv run uvicorn src.main:app`), as três páginas carregam e o fluxo gerar, aprovar e rejeitar funciona contra o banco local. Registrar no comentário o que foi conferido.
- [ ] `uv run pytest -q -m "not externo"` verde.
