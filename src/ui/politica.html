Como o sistema entende o ERP

Aqui não é preferência: é como o sistema lê os dados do ERP hoje. Se algo estiver errado, avise o desenvolvedor.

O que é a quantidade "reservada" no estoque? Ela já está vendida e não pode contar como disponível?
O sistema usa só a quantidade disponível e ignora a reservada.
Um pedido de compra aprovado, mas que ainda não foi enviado ao fornecedor, já conta como mercadoria a caminho?
Sim. Rascunho não conta.
O pedido mínimo por produto (MOQ) é uma quantidade mínima, ou tem que ser múltiplo de uma caixa fechada?
Quantidade mínima, sem múltiplo.
Um pedido que já está a caminho sempre chega antes de um pedido novo que eu faço hoje?
O sistema assume que sim.
Para medir quanto um produto vende por mês, a média dos últimos 6 meses faz sentido para vocês?
O sistema usa a média dos 6 últimos meses fechados. Esta não é configurável por enquanto.
